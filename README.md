# 🧠 The Sentient Archive

> **"I believe in code that feels alive. Clean systems. Sharp logic. Software that doesn't just run — it resonates."**

Welcome to the source code of **The Sentient Archive**, my personal interactive portfolio. Designed with a blend of hyper-modern aesthetics and high-performance engineering, this portfolio is built to reflect my philosophy as a Software Engineer: creating systems that think, learn, and impress.

🌐 **Live Website**: [Mridul Chundaran Portfolio](https://mridul010.github.io/Portfolio/)

---

## 🚀 Features

- **Buttery-Smooth 60FPS Architecture:** Custom JavaScript scroll engine and scrollbars decoupled from layout repaints for maximum fluidity.
- **Dynamic Glassmorphism HUDs:** Interactive Discovery sections simulating frosted glass panels floating over the background (`backdrop-filter`) with pure CSS variables.
- **Hardware-Accelerated Custom Cursor:** An inverted intelligent cursor that magnetically tracks pointers using `translate3d` GPU acceleration to prevent frame drops.
- **Context-Aware Light/Dark Engine:** A highly complex CSS custom property framework (`var(--primary)`, `var(--glass)`, `var(--overlay)`, etc.) allowing instantaneous shifts between a sleek Sentient Dark mode and an airy Research Light setting.
- **Particle & Fluid WebGL Backgrounds:** Powered by `three.js` and `vanta.js` to create subtle neural networks or flowing fluid aesthetics matching the theme.

---

## 🛠️ The Arsenal (Tech Stack)

Although built with a lightweight footprint to preserve frame rates, this architecture leverages best-in-class concepts:

- **HTML5 & Vanilla DOM Control:** Pure structural HTML eliminating heavy framework overhead to ensure instant load times.
- **CSS3 with Flex/Grid Systems:** Complete responsive design supporting every device layout, powered by a robust native CSS variable token system.
- **JavaScript (ES6+)**: Custom scripting for handling dynamic UI changes, event listeners, and performance routing.
- **GSAP (GreenSock Animation Platform):** Industry-standard timeline engine manipulating `ScrollTrigger` and complex sequential load-in animations.
- **Three.js & Vanta.js:** Driving the interactive ambient 3D backgrounds.
